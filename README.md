# AdaptiveTutor - Adaptive Quiz Engine

An AI-powered adaptive learning platform for tutors and students. Tutors create classrooms and quizzes and track how their students are doing; students practise any subject with questions that adapt to their level in real time.

## Who it is for

- **Students** - free practice on any topic, adaptive classroom quizzes, Socratic hints, explanations and spaced-repetition reviews
- **Tutors** - classrooms, assigned quizzes (including quizzes generated from uploaded PDFs), proctoring, class analytics and AI re-teaching suggestions

## Core Adaptive Engine

**IRT (Item Response Theory):** a Rasch 1PL model estimates learner ability (θ) after every answer, and the next question is calibrated to it.

**DAG-Based Prerequisites:** NetworkX topic graphs make sure foundational concepts are mastered before advanced ones.

**Misconception Detection:** wrong answers are classified and tagged, so hints and re-teaching target the actual misunderstanding.

**Spaced Repetition:** the SM-2 algorithm schedules reviews of weak concepts based on forgetting curves.

## AI Components

**Question Generation:** questions are generated by an LLM on Groq from the topic, subtopic, difficulty and Bloom's taxonomy level.

**Socratic Mode:** a 5-level hint ladder guides learners with questions instead of handing over the answer.

**Explanation Calibration:** explanations are tuned to the learner's current ability level.

**Document to Quiz:** tutors upload a PDF and get a structured quiz built from its content.

## Quick Start (local development)

```bash
# Backend
cd backend
cp .env.example .env          # then fill in GROQ_API_KEY
pip install -r requirements-dev.txt
python -m uvicorn app.main:app --reload --port 8000

# Frontend
cd frontend
cp .env.example .env.local
npm install
npm run dev
```

The app runs at http://localhost:3000 and the API at http://localhost:8000 (docs at `/docs`, health check at `/health`). Without `DATABASE_URL`, the backend uses a local SQLite file.

Run the backend tests with `python -m pytest tests` from the `backend` folder.

## Deployment

- **Backend:** build `backend/Dockerfile`, or use `backend/Procfile` on hosts that run Python directly. Set `ENVIRONMENT=production`, `SECRET_KEY`, `DATABASE_URL` (Postgres), `ALLOWED_ORIGINS`, `GROQ_API_KEY` and `GROQ_MODEL`. See `backend/.env.example` for every setting.
- **Frontend:** deploy the `frontend` folder (for example on Vercel) with `NEXT_PUBLIC_API_URL` set to the backend URL, without `/api`.

## Architecture

```
frontend/ (Next.js)     → User interface for students and tutors
backend/ (FastAPI)      → API endpoints + business logic
  ├── agents/           → AI services (Groq)
  ├── irt/              → Rasch model theta estimation
  ├── dag/              → Prerequisite topic graphs
  ├── mastery/          → Learning progress calculation
  └── misconceptions/   → Error pattern analysis
```
